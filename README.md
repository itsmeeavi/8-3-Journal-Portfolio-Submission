# CS 330 Computational Graphics and Visualization

## Project Reflection

### How Do I Approach Designing Software

In this project I worked on creating a 3D study desk scene using OpenGL and C++ and it was  different experience for me because I never worked with this much of 3D graphics before.

I created scene with desk, chair, lamp, books, coffee mug and some other small objects to make it look like real study area.

One of the new skills I learned was how to use different basic shapes to create objects that looks more realistic when they are put together, I also learned about positioning, scaling, rotating objects and applying different textures and materials

My design process was mostly starting with the bigger objects first and then working on smaller details, I had to think about where each object should be placed and how everything would look together from the camera view

Sometimes the objects were not looking like I wanted so I had to change their size or position and check again

I think this design approach can help me in future projects because I learned that planning things before coding makes the process easier and breaking the work into smaller parts also help to avoid confusion

### How Do I Approach Developing Programs

While developing this project I used C++ and OpenGL to create and display the 3D scene and I also worked with different functions for managing the objects and camera movement

The SceneManager was used for creating the objects and setting up the textures, materials and lighting while the ViewManager was used for controlling the camera and different viewing options

I learned how different shapes like boxes, cylinders, spheres and cones can be combined to make objects such as the desk lamp and coffee mug

I also worked with lighting and used directional light and point light to make the objects look more natural in the scene

One thing I learned during this project was that even a small change in the code can make a big difference in how the scene looks

Iteration was a important part of my development because I had to keep checking the scene and making changes to the objects, camera and lighting

As I moved through the milestones I started to understand better how different parts of the program works together and how the scene was being created

At the beginning I was mostly focusing on getting the objects to appear but later I started paying more attention to their placement, colors, lighting and how the user can move around the scene

This project helped me become more comfortable with testing my code and trying different solutions when something was not working the way I expected

I also realized that completing a program is not just about making the code run but also making sure the final result looks and works properly

### How Can Computer Science Help Me in Reaching My Goals

This course helped me understand another side of computer science that I did not have much experience with before

Before taking this course I mostly thought about programming as writing code to solve problems but working with 3D graphics showed me how programming can also be used to create visual environments

I learned about OpenGL, transformations, textures, lighting and camera controls which gave me a better understanding of how computer graphics works

I think these skills will be useful in my future education because I will be able to apply the problem solving and programming knowledge I learned here in other computer science courses

The experience of working through the milestones also helped me understand why planning and testing are important when developing a larger project

For my professional goals I believe the skills from this course can help me become a better software developer because it improved my understanding of how different components of a program work together

Even if I do not directly work in 3D graphics in the future, I can still use what I learned about debugging, designing software and improving programs through testing

Overall this project was challenging for me sometimes but it also helped me learn new things and gain more confidence in working with C++ and computer graphics
